# FIIO-DISC

FIIO DISC 社区固件与刷机资源。

## 最新候选版本：V449

V449 在 V446 之后继续调整纯音无缝接续、蓝牙封面消息处理和睡眠关机恢复。
固件已完成构建并核对 SHA-256；本轮尚无真机回归结果，因此按候选版发布，
不将指令模拟检查等同于尾段重播已在设备上彻底解决。

- [V449 候选版与校验文件](https://github.com/wanan522z/FIIO-DISC/releases/tag/v449)
- [此前发布的 V446 Stable](https://github.com/wanan522z/FIIO-DISC/releases/tag/v446)
- [全部 Releases](https://github.com/wanan522z/FIIO-DISC/releases)

### V449：纯音无缝接续

- 普通纯音 PCM 播放改为在解码器实际读到曲尾时请求下一曲，每曲只请求一次，
  减少整首顺播时进度计时偏差导致准备过晚或漏触发的风险。
- 等待下一曲的解码句柄和播放信息全部就绪后再交接，避免信息尚未准备完就切换。
- 下一曲准备有等待上限；超时交回原有结束流程，暂停、切歌或模式改变时交回
  原状态机处理，不重新提交旧音频数据。
- 保留 CUE 毫秒精度修复；特殊解码路径和不同格式之间的原有处理保持有效。

### V447–V448：封面与关机状态

- V447 调整入站消息队列的持锁范围，降低处理封面或界面消息时阻塞后续接收的风险。
  手机通过其他蓝牙设备播放时，播放器仍可接收封面更新。
- V448 在关闭播放模式后清理蓝牙音轨及采样率缓存，并处理关机命令异常返回，
  减少睡眠关机后音频状态残留、无声或后续关机失效的风险。

### 保留的 V439–V446 调整

- 修正早期封面分支的跳转延迟槽覆盖和栈泄漏。
- 蓝牙 PCM 保护使用固定连接窗口，避免跨 App 播放或读线程重建反复延长等待。
- 清理待机关闭状态残留，并限制无封面场景下的 UI 消费者生命周期。
- 保留息屏停止封面旋转、亮屏刷新一次最新封面并继续旋转的行为。

## R5 一键刷机工具说明

`FIIO-DISC-V427-Stable-OneClick-R5.zip` 是保持原样的 V427 R5 工具包。
**工具默认选中包内 V427 固件。刷 V449 时，必须在工具界面另选单独下载的
`FIIO-DISC-V449-Candidate-rootfs.squashfs`。** 工具会根据所选固件自动生成 cfg。
弹出“非随包 V427 固件”提示时，先核对 V449 文件名与 SHA-256，再确认继续。

R5 工具 ZIP 的 SHA-256：

```text
0a6bf8625b809ad76243dbdaec9503933877b95b7e6643dba37c5bf275c00fb0  FIIO-DISC-V427-Stable-OneClick-R5.zip
```

解压后请先完整阅读包内的 `刷机教程.md`：

1. 首次使用先运行 `Install-USB-Driver.cmd`。
2. 设备关机并先不要插线，运行 `FIIO-DISC-OneClick.cmd`，选择并核对 V449 固件。
3. 点击“一键刷入”，等待 Cloner 自动打开，然后手动点一次“开始”。
4. 确认黑色 core 窗口出现 `start burner` 后，按住音量 - 再插入 USB 数据线。
5. boot 进度条超过 50% 后才能松开音量键。
6. rootfs 进度条走完并变成绿色后才能拔线。

> 警告：刷机有风险。刷入失败无法开机时，需要拆机并拔掉电池；不连接电池，
> 按相同方法重新刷入，刷入成功后再接回电池。

工具会按实际保存目录生成 cfg，只读写主 rootfs，`force_erase=0`。可选备份保存
在工具目录的 `backup` 文件夹。

Cloner 2.5.58.6 及 USB 驱动来自原始第三方工具，其原始文档保留在 Cloner 目录。

## V449 验证范围与反馈

已通过 73 组轻量指令场景检查，覆盖进度偏差、下一曲准备先后顺序、超时、
暂停和切歌等控制流，并核对固件实物与构建记录的 SHA-256。
这些检查不模拟真实 TF 卡延迟、音频输出或 DAC，仍需设备回归测试。

建议用 4–5 首同格式歌曲从头完整顺播，至少跨过三次自动切歌；再从倒数
20 秒、倒数 3 秒起播作对照。反馈时分别记录重复尾段、尾段截断、间隙和
跳曲，并附歌曲顺序、格式及起播位置。另检查尾部暂停恢复、不同格式切换、
睡眠关机后的蓝牙播放，以及手机通过其他设备播放时的封面更新。

## V427 更新日志

### 修复

- 修复了纯音模式 Wi-Fi 连接时，蓝牙模式下重启自动进入蓝牙模式时无法打开蓝牙的问题。
- 曾调整纯音连续播放的尾段重复问题；后续仍有概率性复现，V449 继续修正接续时序。
- 修复纯音封面不居中的问题。
- 修复蓝牙接收标题偶现不刷新。

### 新增与调整

- 全局替换 MiSans（韩文除外）。
- 调低白点值，屏幕看着更黄更高级。
- 新增锁屏开关。
- 均衡器新增 PEQ。
- 新增蓝牙封面功能，同时蓝牙、流媒体模式拥有状态栏，可调节不影响当前正常运行的基础设置。
- 重构了蓝牙、流媒体、纯音播放界面的 UI。纯音播放界面简洁模式屏幕一圈改为进度条，可以切换颜色。
- 流媒体新增 DLNA 功能，适配安卓手机。
- 新增暂停键双击下一曲，三击上一曲。
- 新增手动屏幕常亮选项、封面页常亮选项，拉满摆件属性。
- 重构状态栏图标和显示内容。
- 纯音播放列表可临时拖动排序、删除（不改动原始顺序）。随机模式展示随机后顺序。
- 调慢封面旋转速度，状态栏加入封面旋转快捷开关。
- 蓝牙接收模式音量 +30，使手机音量不用开大就能和纯音模式音量对齐，听起来确实保留更多动态。
- 蓝牙接收模式可主动调节采样率，推荐 48 kHz，理论上可保留更多动态。
