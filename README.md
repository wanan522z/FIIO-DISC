# FIIO-DISC

FIIO DISC 社区固件与刷机资源。

## 当前版本：V439 Stable

V439 以 V427 Stable 为基线，主要修复：

- 蓝牙接收模式切歌后概率性断联、无法回连的问题；
- V32 遗留的两处 MIPS 延迟槽覆盖；
- 封面恢复分支每次命中造成的 32 字节栈泄漏；
- 息屏期间封面仍在后台旋转的问题。

息屏切歌后，亮屏时仍保留一次新封面刷新；没有新增蓝牙定时器。

固件、刷机工具和 SHA-256 校验值请从仓库的
[Releases](https://github.com/wanan522z/FIIO-DISC/releases) 页面下载。

## R5 一键刷机工具说明

`FIIO-DISC-V427-Stable-OneClick-R5.zip` 是保持原样的 V427 R5 工具包。
需要刷入 V439 时，请在工具界面选择单独下载的
`FIIO-DISC-V439-Stable-rootfs.squashfs`；工具会根据所选固件自动生成 cfg。

解压后请先完整阅读包内的 `刷机教程.md`：

1. 首次使用先运行 `Install-USB-Driver.cmd`。
2. 设备关机并先不要插线，运行 `FIIO-DISC-OneClick.cmd`。
3. 点击“一键刷入”，等待 Cloner 自动打开，然后手动点一次“开始”。
4. 确认黑色 core 窗口出现 `start burner` 后，按住音量 - 再插入 USB 数据线。
5. boot 进度条超过 50% 后才能松开音量键。
6. rootfs 进度条走完并变成绿色后才能拔线。

> 警告：刷机有风险。刷入失败无法开机时，需要拆机并拔掉电池；不连接电池，
> 按相同方法重新刷入，刷入成功后再接回电池。

工具会按实际保存目录生成 cfg，只读写主 rootfs，`force_erase=0`。可选备份保存
在工具目录的 `backup` 文件夹。

R5 包内 V427 固件 SHA-256：

```text
48E0CA9FDE71EFCE215D9104026DCFBBB9EBD44AE328FC21FF4F8A240892A462
```

Cloner 2.5.58.6 及 USB 驱动来自用户提供的原始第三方工具，其原始文档保留在
Cloner 目录。

## V427 更新日志

### 修复

- 修复了纯音模式 Wi-Fi 连接时，蓝牙模式下重启自动进入蓝牙模式时无法打开蓝牙的问题。
- 修复了纯音连续播放时尾音会多一段的问题。
- 修复纯音封面不居中的问题。
- 修复蓝牙接收标题偶现不刷新。

### 新增与调整

- 全局替换 MiSans（韩文除外）。
- 调低白点值，屏幕看着更黄更高级。
- 新增锁屏开关。
- 均衡器新增 PEQ。
- 新增蓝牙封面功能，同时蓝牙、流媒体模式拥有状态栏，可调节不影响当前正常运行的基础设置。
- 重构了蓝牙、流媒体、纯音播放界面的 UI。纯音播放界面简洁模式屏幕一圈改为进度条，可以切换颜色。
- 流媒体新增 DLNA 功能，适配安卓手机。
- 新增暂停键双击下一曲，三击上一曲。
- 新增手动屏幕常亮选项、封面页常亮选项，拉满摆件属性。
- 重构状态栏图标和显示内容。
- 纯音播放列表可临时拖动排序、删除（不改动原始顺序）。随机模式展示随机后顺序。
- 调慢封面旋转速度，状态栏加入封面旋转快捷开关。
- 蓝牙接收模式音量 +30，使手机音量不用开大就能和纯音模式音量对齐，听起来确实保留更多动态。
- 蓝牙接收模式可主动调节采样率，推荐 48 kHz，理论上可保留更多动态。
